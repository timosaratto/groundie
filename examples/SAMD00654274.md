## AMR classes

The same hits by drug class: how many, which genes, and the best identity among them.

```DataTable classes
source: hits
filters:
  element_type: AMR
group_by: [element_class]
measures:
  hits: count(*)
  genes: list(element_symbol)
  best_identity: max(pct_identity)
sort: [element_class]
display:
  element_class: Class
  hits: Hits
  genes: Genes
  best_identity: Best identity (%)
```
